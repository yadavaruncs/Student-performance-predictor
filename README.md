# 🎓 EduPredict AI — Student Performance Prediction with AI Study Assistant

An end-to-end machine learning application that predicts a student's likely
grade (A–F) from academic and personal factors, and generates personalized,
encouraging study advice using a small **local** Hugging Face Transformer
model — no cloud APIs, no API keys.

Built as a realistic, interview-friendly project for a 3rd-year Computer
Science student: complete enough to demonstrate real ML skills, simple
enough to fully understand and explain.

## 🎯 Problem Statement

Teachers and academic advisors often notice struggling students too late.
EduPredict AI uses easily-collected data (attendance, study hours, previous
grades, support systems) to flag likely academic outcomes early, and
immediately pairs that prediction with concrete, encouraging next steps —
not just a number.

## 📊 Dataset

This project uses the same feature schema as the well-known **UCI "Student
Performance"** and **Kaggle "Students Performance in Exams"** datasets:

`age, gender, attendance_percentage, weekly_study_hours, previous_grade,
internet_access, parent_education, family_support, failures → grade`

> **Note on the shipped dataset:** the development sandbox used to build
> this project had no internet access, so `generate_dataset.py` was used to
> synthesize `data/student.csv` — ~1,200 rows with the same columns and
> realistic value ranges, generated from a real underlying signal (better
> attendance / more study hours / fewer failures → better grades, plus
> random noise) so the pipeline has genuine patterns to learn, not just
> random noise. **To use the real Kaggle/UCI dataset instead:** download
> it, rename columns to match the schema above, and save it as
> `data/student.csv` — no other file needs to change.

## 🔁 ML Workflow

```
Raw CSV → Data Cleaning → Feature Engineering → Encoding → Scaling
        → Train/Test Split → Train 3 Models → Evaluate → Best Model
        → Save Artifacts → Streamlit App (Predict + AI Advice)
```

1. **Data Cleaning** — drop duplicates, fill missing values (median for
   numeric, mode for categorical), drop leaky columns.
2. **Feature Engineering** — `study_efficiency` (study hours × attendance
   rate) and `academic_risk` (flag for 2+ past failures).
3. **Encoding** — `LabelEncoder` for categorical columns (all are binary or
   naturally ordered, so a single integer column is appropriate here; the
   notebook also demonstrates `OneHotEncoder` for comparison).
4. **Scaling** — `StandardScaler` on numeric columns. Needed for Logistic
   Regression (gradient-based, sensitive to feature scale) but not for
   Decision Tree / Random Forest (threshold-based splits are scale-invariant).
5. **Models** — Logistic Regression, Decision Tree, Random Forest, all with
   `class_weight="balanced"` to counter class imbalance (few "A" grades).
6. **Evaluation** — Accuracy, Precision, Recall, F1 (macro-averaged),
   Confusion Matrix. Macro F1 is used to pick the best model since accuracy
   alone can be misleading on imbalanced classes.

## 📈 Results

*(from a run on the shipped synthetic dataset — numbers will differ with
the real dataset or a different random seed)*

| Model | Accuracy | Precision | Recall | F1 (macro) |
|---|---|---|---|---|
| Logistic Regression | 0.508 | 0.411 | 0.458 | **0.421** ← best |
| Decision Tree | 0.375 | 0.302 | 0.312 | 0.298 |
| Random Forest | 0.517 | 0.374 | 0.370 | 0.371 |

**Best model: Logistic Regression**, selected by macro F1 score. Overall
accuracy is modest (~50%) because the synthetic target intentionally
includes random noise on top of the real signal — a realistic reflection
of how noisy predicting human academic outcomes actually is. All plots
(grade distribution, attendance distribution, correlation heatmap, feature
importance, confusion matrix, model comparison) are generated by
`train_model.py` and saved to `plots/`.

## ⚙️ Installation & Setup

```bash
# 1. Clone / unzip the project, then move into it
cd EduPredict-AI

# 2. (Recommended) create a virtual environment
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Generate the dataset (only needed if data/student.csv is missing —
#    it's already included in this project)
python generate_dataset.py

# 5. Train the models (creates models/*.pkl and plots/*.png)
python train_model.py

# 6. Launch the app
streamlit run app.py
```

The first time the **Predict** page runs, `transformers` will download
`google/flan-t5-small` (~80MB) — this requires internet access once; after
that it's cached locally and works fully offline.
